**QRCraft Studio** is a professional-grade, local-first QR Code customization engine. Built with a "Studio Workspace" philosophy, it allows users to transform generic QR codes into bespoke brand assets with high-precision rendering, premium frames, and real-time readability analysis.

## ✨ Key Features

- **🎯 Precision Matrix Engine**: Supports 4 distinct dot styles: *Classic Square*, *Connected Smooth* (Spotify-style), *Modern Dots*, and *Diamond Ketupat*.
- **🖼️ Premium Frame Library**: Includes 10 algorithmically generated frames (Cyber Bracket, Polaroid, Neon Shadow, Double Line, etc.) without external image dependencies.
- **🛡️ Scan Stability Gauge**: A real-time UX feature that calculates color contrast and data density to ensure the generated QR code remains scannable.
- **🎨 Monochrome Luxury UI**: A sleek, dark-themed minimalist interface designed for a focused creative workflow.
- **logo Branding Injector**: Seamlessly embed brand logos into the center of the QR code with automatic background masking and error correction optimization.
- **🚀 Zero-API / Local-First**: All rendering happens on the client-side via HTML5 Canvas API. No data ever leaves the user's browser, ensuring 100% privacy and instant performance.

---

## 🛠️ Tech Stack

- **Frontend Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite (Ultra-fast HMR)
- **Styling**: Tailwind CSS (Monochrome Studio Theme)
- **Core Engine**: HTML5 Canvas API & `qrcode` logic
- **State Management**: Reactive Global Store Pattern
